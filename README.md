# Odin Landing Page

A static landing page project built with HTML and CSS based on a provided design from The Odin Project.

## Project Overview
This project includes:
- a top navigation bar with logo and links
- a hero section with headline, supporting text, and call-to-action button
- an information section with image cards and captions
- a testimonial/quote section
- a signup banner
- a footer with copyright information

## Files
- `index.html` — page structure and content
- `style.css` — layout and styling
- `images/` — project images and assets

## How to View
Open `index.html` in a browser to view the landing page locally.
